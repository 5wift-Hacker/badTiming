# Bad Timing

A portfolio SwiftUI app showcasing modern glass-themed iOS development. Initially built before Liquid Glass released. Simplifies stretching by allowing users to choose a stretch group or theme preset, and push a single button to flow through all the stretches.

## ✨ Main Features

- **'One-Button' Start**: Start stretching in almost a 'one-button' fashion. The idea is to keep it super simple to make it easy to get started when its bad timing.
- **Timers**: Utilizing timers in SwiftUI to receive updates from the ticks, and apply it to different sections of the app - such as pausing on the stretch info screen, or auto-starting or resetting through different actions.
- **Glass Theme**: Fluid, glassy navigation crafted before Liquid Glass was announced.
- **Polished Design**: Minimalist, simple, and easy visuals for an quick, interactive and useful user experience.
